# ADR 登记

ADR(Architecture Decision Records)记录影响项目长期结构的设计决策。
规则(docs/13_CODING_AI_GUIDE.md):

- 关键设计决策必须通过 ADR 保留。
- ADR 只新增、不覆盖;新决策写新编号。
- 状态:`Proposed` → `Accepted` / `Superseded by ADR-XXX`。
- 格式:背景(为什么)→ 现状 → 决策 → 影响 → 后续动作。
